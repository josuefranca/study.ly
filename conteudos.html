1. Fundamentos da Programação

Lógica de Programação

Lógica de programação é a capacidade de organizar instruções para resolver um problema.

Algoritmo

Um algoritmo é uma sequência de passos para realizar uma tarefa ou solucionar um problema.

Pensamento Computacional

É uma forma de resolver problemas utilizando conceitos presentes na computação.

  • Decomposição
  • Reconhecimento de padrões
  • Abstração
  • Algoritmos

2. O que é um computador?

Um computador é uma máquina capaz de receber, processar, armazenar e produzir informações.

Input

Dados que entram no sistema.

Output

Informações produzidas pelo sistema.

Frontend

Parte da aplicação com a qual o usuário interage.

Backend

Parte responsável pela lógica e processamento no servidor.

Memória

Área utilizada para armazenar temporariamente ou permanentemente informações.

3. Fluxogramas

Fluxogramas representam visualmente os passos de um algoritmo.

Principais elementos

  • Início e fim
  • Processo
  • Entrada e saída
  • Decisão
  • Setas de fluxo

Onde criar?

Você pode criar fluxogramas usando ferramentas como diagrams.net, Lucidchart ou outras ferramentas de diagramas.

6. Estruturas Condicionais

if, elif e else

idade = 18

if idade >= 18:
    print("Maior de idade")

elif idade == 17:
    print("Quase 18")

else:
    print("Menor de idade")

match / case

opcao = 2

match opcao:

    case 1:
        print("Início")

    case 2:
        print("Configurações")

    case 3:
        print("Sair")

7. Estruturas de Repetição

while

contador = 0

while contador < 5:
    print(contador)
    contador += 1

for

for numero in range(5):
    print(numero)

Loops

Loops são estruturas utilizadas para repetir determinadas instruções.

Do while

Python não possui um comando do while nativo. É possível reproduzir esse comportamento utilizando outras estruturas.
